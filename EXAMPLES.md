```
Authoritarianism
```

- Single-party rule ⊆ Authoritarianism (HIERARCHICAL)

## Tips for Good Analysis

1. **Be Specific**: Use clear, well-defined concepts rather than vague terms
2. **Group Coherently**: Ideas within a group should share some common theme
3. **Diverse Groups**: More interesting results come from comparing distinct concept groups
4. **Balanced Groups**: Try to have similar numbers of ideas in each group (3-8 ideas each)
5. **Context Matters**: Relationships can vary based on domain and context

## Interpreting Results

### Certainty Scores
- **0.9-1.0**: Very strong relationship, multiple clear evidence points
- **0.7-0.9**: Strong relationship with clear evidence
- **0.5-0.7**: Moderate relationship, may be context-dependent
- **0.3-0.5**: Weak relationship, speculative connection
- **0.0-0.3**: Very weak or uncertain relationship

### Relationship Symbols Quick Reference
- ⊥ Contradictory (mutually exclusive)
- → Implicative (A implies B)
- ⊆ Hierarchical (A is type of B)
- ⟿ Evolutionary (B evolved from A)
- ≈ Analogous (structural similarity)
- ≡ Synonymous (same meaning)
- ≠ Antonymous (opposites)
- ∈ Part-Whole (A is part of B)
- ⇒ Causal (A causes B)

## Advanced Usage

### Exploring Specific Relationships

When viewing the graph, use arrow keys to cycle through relationships and see:
- Which ideas are connected
- The type of relationship
- The certainty score
- A brief description

### Iterative Refinement

1. Run initial analysis
2. Note unexpected or missing relationships
3. Refine your idea groups
4. Re-analyze to see improved results

### Domain-Specific Analysis

The system works best when:
- Ideas are from a consistent domain
- Concepts have clear definitions
- Relationships are logically structured
- Groups represent different perspectives or categories
